💡 Cara Penggunaan di Admin Panel

  1. Unggah foto produk atau banner toko pada kotak upload di samping.
  2. Klik tombol "Salin URL" pada hasil upload.
  3. Buka halaman Admin (atau Wails Desktop App) pada form produk/banner.
  4. Tempelkan (*paste*) URL tersebut ke kolom "URL Foto Produk" atau "URL Banner".
  5. Klik Simpan / Sync! Gambar akan langsung tampil di website.

🔗 Endpoint API untuk Integrasi Otomatis:

POST http://localhost:4000/api/upload

Menerima format multipart/form-data dengan nama field file atau image.
